# Agentize

Dùng `/ck:agentize` để đóng gói một tính năng hiện có thành CLI hoặc MCP server tái sử dụng, gồm giao thức truyền tải, xác thực, tài liệu, test và CI.

```text
/ck:agentize expose module báo cáo này dưới dạng MCP server
```
