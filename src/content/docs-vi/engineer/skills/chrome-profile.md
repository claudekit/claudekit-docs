# Chrome Profile

Dùng `/ck:chrome-profile` khi tự động hóa cần cookies, tài khoản đăng nhập hoặc một hồ sơ Chrome cụ thể. Skill hỗ trợ tìm profile, kiểm tra DevTools và chọn tab theo URL.

```text
/ck:chrome-profile kết nối profile Chrome đang đăng nhập và kiểm tra tab hiện tại
```
