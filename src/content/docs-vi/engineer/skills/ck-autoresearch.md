# Autoresearch

Dùng `/ck:autoresearch` để chọn workflow lặp tự động phù hợp với mục tiêu, metric và guardrail an toàn của bạn.

```text
/ck:autoresearch chọn vòng lặp phù hợp để tăng test coverage
```
