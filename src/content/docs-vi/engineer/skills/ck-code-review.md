# Code Review

Dùng `/ck:code-review` để tìm bug, regression, rủi ro bảo trì và khoảng trống xác minh trong diff, PR, commit hoặc codebase.

```text
/ck:code-review các thay đổi chưa commit
/ck:code-review PR 42
```
