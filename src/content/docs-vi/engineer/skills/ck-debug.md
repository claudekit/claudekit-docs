# Debug

Dùng `/ck:debug` cho bug, test failure, lỗi CI/CD, vấn đề hiệu năng, log, database hoặc hành vi bất thường cần chứng minh nguyên nhân.

```text
/ck:debug điều tra vì sao endpoint đăng nhập trả về lỗi 500
```
