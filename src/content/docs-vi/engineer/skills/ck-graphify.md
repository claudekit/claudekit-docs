# Graphify

Dùng `/ck:graphify` để phân tích kiến trúc, khám phá quan hệ giữa file và điều hướng codebase bằng graph thay vì quét lại toàn bộ nội dung.

```text
/ck:graphify tạo graph của repository và hiển thị luồng xác thực
```
