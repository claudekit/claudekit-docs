# Loop

Dùng `/ck:loop` khi một metric cơ học như coverage, hiệu năng hoặc bundle size có thể quyết định giữ hay bỏ từng thử nghiệm.

```text
/ck:loop chạy 10 vòng để giảm thời gian build
```
