# Predict

Dùng `/ck:predict` trước tính năng lớn hoặc thay đổi rủi ro để tìm sớm vấn đề kiến trúc, bảo mật, hiệu năng và UX.

```text
/ck:predict đánh giá đề xuất thay đổi hệ thống phân quyền
```
