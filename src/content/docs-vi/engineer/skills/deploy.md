# Deploy

Dùng `/ck:deploy` khi cần publish, host hoặc đưa ứng dụng lên production. Skill đọc cấu hình để chọn workflow phù hợp cho nền tảng đích.

```text
/ck:deploy triển khai ứng dụng này lên Cloudflare
```
