# DOCX

Dùng `/ck:docx` để tạo hoặc chỉnh sửa `.docx`, giữ định dạng, xử lý tracked changes, comments, template và trích xuất văn bản.

```text
/ck:docx redline contract.docx và giữ nguyên styles
```
