# Excalidraw

Dùng `/ck:excalidraw` để tạo architecture diagram, data flow, workflow hoặc bản đồ codebase trên canvas có thể chỉnh sửa.

```text
/ck:excalidraw vẽ kiến trúc dịch vụ và các luồng dữ liệu
```
