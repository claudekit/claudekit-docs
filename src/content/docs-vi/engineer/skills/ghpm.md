# GitHub Project Management

Dùng `/ck:ghpm` cho lập kế hoạch bằng issue, Projects board, trạng thái PR, workflow label, CI và handoff giữa người hoặc agent.

```text
/ck:ghpm phân loại issue mở và đề xuất milestone tiếp theo
```
