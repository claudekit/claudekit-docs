# LLMS

Dùng `/ck:llms` để tạo chỉ mục `llms.txt`, tóm tắt tài liệu và context thân thiện với mô hình AI theo đặc tả llmstxt.org.

```text
/ck:llms tạo llms.txt cho website tài liệu này
```
