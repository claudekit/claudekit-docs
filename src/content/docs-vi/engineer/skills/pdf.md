# PDF

Dùng `/ck:pdf` cho text, table, biểu mẫu, tạo file, gộp hoặc tách trang và xử lý PDF hàng loạt.

```text
/ck:pdf trích xuất tất cả bảng từ report.pdf sang CSV
```
