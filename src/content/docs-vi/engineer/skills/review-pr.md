# Review PR

Dùng `/ck:review-pr` với số hoặc URL PR/MR để kiểm tra trùng lặp, tiêu chuẩn dự án, correctness, security, breaking change và chất lượng code.

```text
/ck:review-pr 42
/ck:review-pr 42 --fix
```
