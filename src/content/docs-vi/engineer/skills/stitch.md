# Stitch

Dùng `/ck:stitch` để tạo prototype UI từ prompt, xuất Tailwind hoặc HTML và chuẩn bị tài liệu thiết kế cho bước triển khai.

```text
/ck:stitch tạo dashboard quản trị cho SaaS
```
