# Xia

Dùng `/ck:xia` để nghiên cứu cách repository khác triển khai một feature rồi chuyển hoặc thích nghi hành vi đó vào stack hiện tại.

```text
/ck:xia port workflow xác thực từ repository tham chiếu này
```
