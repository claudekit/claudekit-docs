# XLSX

Dùng `/ck:xlsx` cho `.xlsx`, `.csv`, `.tsv`, formula, formatting, pivot table, chart và recalculation. Workflow giữ nguyên template hiện có và kiểm tra lỗi công thức.

```text
/ck:xlsx phân tích sales.xlsx và thêm worksheet dự báo
```
