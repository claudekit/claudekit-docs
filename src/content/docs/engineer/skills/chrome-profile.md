# Chrome Profile

Use `/ck:chrome-profile` when browser automation needs an existing Chrome profile, cookies, signed-in account, or deterministic profile target. It provides profile discovery, live DevTools probing, setup guidance, and URL-based tab selection.

```text
/ck:chrome-profile connect to my signed-in Chrome profile and inspect the active tab
```

This skill is available through the ClaudeKit Engineer plugin in Claude Code and Codex.
