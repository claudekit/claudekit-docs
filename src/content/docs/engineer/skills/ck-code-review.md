# Code Review

Use `/ck:code-review` to find bugs, regressions, maintainability risks, reliability issues, and verification gaps. It supports pending changes, PR numbers, commit hashes, and full-codebase scans.

```text
/ck:code-review pending changes
/ck:code-review PR 42
```

Pair it with [Review PR](/docs/engineer/skills/review-pr) when the review also needs forge-specific PR handling.
