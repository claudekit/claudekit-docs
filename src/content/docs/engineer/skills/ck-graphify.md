# Graphify

Use `/ck:graphify` for codebase understanding, architecture analysis, cross-file relationship discovery, and token-efficient navigation. It turns code and documents into a graph that can be queried instead of repeatedly rescanning raw files.

```text
/ck:graphify build a graph of this repository and show the authentication flow
```

The skill is bundled with ClaudeKit Engineer; no separate global skill installation is required.
