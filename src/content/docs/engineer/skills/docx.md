# DOCX

Use `/ck:docx` to create or edit `.docx` files, preserve formatting, review tracked changes, add comments, extract text, or modify templates.

```text
/ck:docx redline contract.docx and preserve all existing styles
```

DOCX is one of four document skills bundled in the Engineer payload alongside [PDF](/docs/engineer/skills/pdf), [PPTX](/docs/engineer/skills/pptx), and [XLSX](/docs/engineer/skills/xlsx).
