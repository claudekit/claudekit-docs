# GitHub Project Management

Use `/ck:ghpm` for issue planning, Projects boards, PR status, label workflows, CI-driven tracking, and human or agent handoffs through GitHub.

```text
/ck:ghpm triage the open issues and propose the next project milestone
```

The plugin supplies the public `ck:` namespace even though the payload stores a provider-neutral skill identifier.
