# HTML Video

Use `/ck:html-video` for HTML-first promos, explainers, social clips, or data videos. The workflow covers template discovery, local studio customization, Chromium preview, and FFmpeg render verification.

```text
/ck:html-video create a 30-second product launch clip from an HTML template
```

Use [Remotion](/docs/engineer/skills/remotion) when the video should be authored as a React composition.
