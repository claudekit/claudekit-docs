# PDF

Use `/ck:pdf` for PDF text and table extraction, generation, merging, splitting, form filling, document analysis, and batch operations.

```text
/ck:pdf extract every table from report.pdf into CSV files
```

PDF is a supported nested document skill in the shipped Engineer payload and is cataloged as its own public skill.
