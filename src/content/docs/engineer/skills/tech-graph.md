# Tech Graph

Use `/ck:tech-graph` for production-quality architecture, data-flow, sequence, agent, memory, and concept diagrams. It applies layout, routing, labeling, and export rules suitable for published documentation.

```text
/ck:tech-graph diagram the request flow from browser to database
```

Use [Mermaid.js v11](/docs/engineer/skills/mermaidjs-v11) for lightweight inline diagrams.
