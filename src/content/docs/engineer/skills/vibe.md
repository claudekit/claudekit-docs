# Vibe

Use `/ck:vibe` when one workflow should take a GitHub issue, feature request, or bug from worktree setup through planning, implementation, PR review, shipping, and optional merge monitoring.

```text
/ck:vibe https://github.com/example/project/issues/42
```

For narrower work, use [Cook](/docs/engineer/skills/cook), [Fix](/docs/engineer/skills/fix), or [Ship](/docs/engineer/skills/ship) directly.
