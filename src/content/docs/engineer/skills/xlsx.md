# XLSX

Use `/ck:xlsx` for `.xlsx`, `.csv`, and `.tsv` analysis, formulas, formatting, pivot tables, charts, and formula recalculation.

```text
/ck:xlsx analyze sales.xlsx and add a validated forecast worksheet
```

The workflow preserves established workbook templates and verifies that delivered formulas contain no spreadsheet errors.
